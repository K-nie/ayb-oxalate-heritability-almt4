# A candidate locus near an ALMT4 homolog is nominally associated with seed soluble-oxalate variation in African yam bean (*Sphenostylis stenocarpa*), with breeder-decision resources for seed quality

Analysis code and derived result tables for marker-based heritability and candidate-gene
work on 13 seed-quality and anti-nutritional traits in a 95-line (post-QC) African yam
bean DArTseq panel. Covers phenotype exploration, trait PCA, single- and multi-trait
GBLUP, bootstrap and Bayesian marker-based heritability, mixed-model and FarmCPU/mrMLM
GWAS, a directed candidate-gene test at an ALMT4 homolog, candidate-window and
structural/orthology analysis of that locus, and breeder-decision tools (GEBVs, merit
index, optimal contribution selection, usefulness criterion, Smith–Hazel index).

This repository contains the **analysis code and derived result tables** for the study.
Raw genotype and phenotype data are archived separately (see **Data** below); manuscript
drafts and figures are not included (the figures are generated by the scripts here).

## Repository layout

```
scripts/    numbered Python and R analysis scripts (shared helpers: _plotstyle, _pheno, _figstyle)
results/    one directory per analysis stage, each with tables/ and a README.md
            documenting method, inputs, outputs, findings, and caveats
refs/       machine-learning best-practice reference material
```

Each `results/<NN>_*/README.md` is the reproducibility and methods record for that stage:
what it does and why, its inputs, the exact commands and thresholds, the outputs, and the
caveats.

## Reproducing

Scripts run from a single conda environment (`yeast-viz`: numpy, pandas, scikit-learn,
matplotlib, plus the R toolchain for the `.R` steps). Stages are numbered by pipeline
order; run the lower-numbered QC/PCA stage first, then the analysis of interest. Per-stage
READMEs give the exact command and parameters. The Python environment is pinned in
`environment.yml` / `environment_py_requirements.txt`.

## Findings

- **Soluble oxalate carries the only substantial marker-captured heritability signal.** A
  calibrated boundary likelihood-ratio test rejects zero marker-captured variance for
  soluble oxalate (p = 0.0071), though its magnitude is poorly determined at n = 41 (REML
  profile flat above a one-sided 0.14 lower bound).
- **A SNP ~3 kb upstream of an ALMT4 homolog is *nominally* associated with soluble
  oxalate — a candidate, not a confirmed locus.** The anchored SNP at Ss10:15.4 Mb
  (ALMT4_2) was tested as an a-priori candidate (not recovered by the genome-wide scan)
  and carried a nominal directed-test signal (mixed-model Wald p = 0.0014). It rests on six
  carrier lines of 41 (one alternate homozygote; MAF 0.085) and is corroborated across
  methods that are *not* statistically independent, so it is not independent confirmation.
  **No marker reaches genome-wide significance for any trait.**
- **Genomic prediction is modest, and multi-trait GBLUP gives no clear benefit.** 5-fold
  cross-validated predictive ability is r ≈ 0.21–0.23 for total and insoluble oxalate and
  weaker elsewhere; a multivariate GBLUP on the {soluble, insoluble} pair gave no
  improvement that held across cross-validation schemes at n = 41.
- **Breeder-decision tools are released as preliminary resources, not recommendations.**
  Per-accession GEBVs, a merit index (an all-trait and a restricted/primary variant), an
  Allier usefulness-criterion cross ranking, a Meuwissen optimal-contribution solution, and
  a Smith–Hazel index (primary P from the stage-one BLUE phenotypic covariance) are
  provided; the rankings are unstable to reasonable modelling choices and are intended to
  seed, not settle, crossing decisions.
